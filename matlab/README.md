# Legacy MATLAB scripts

This folder preserves the lab's earlier MATLAB monitor-calibration utilities:

- `CalibrateMonitor.m`
- `ValidateCalibration.m`
- `VerifyTiming.m`

These scripts are retained for provenance and compatibility with older lab
workflows. They are separate from the portable PsychoPy implementation in
`../python/` and may depend on the MATLAB environment and hardware-specific
functions used when they were written.
